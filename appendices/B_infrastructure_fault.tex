\section{Replication and execution comparisons}\label{sec:s1-replication}

The corrected Llama-90B Phase~1A run was compared with an independent rerun
and a quantised run confined to one GPU (\cref{tab:s1-replication}).
The independent rerun reproduces the reference closely, with $r=0.9996$,
a mean absolute difference in $\pyes$ of $0.0024$ and 220 of 330 rows
bit-identical. This supports repeatability across the two evaluated nodes
without establishing identical arithmetic under every possible configuration.

The single-GPU 4-bit run avoids transfers between devices, but also changes
numerical precision relative to the bf16 reference. Its correlation is
$r=0.767$, with a mean absolute difference of $0.148$, and its aggregate
score is $+0.1100$ compared with the reference $+0.1530$.
The comparison therefore changes precision and execution configuration
together, and cannot isolate a remaining transfer fault or attribute the
whole difference to either factor. The controlled three-arm experiment
in \cref{tab:app-fault} provides the more direct test of the workaround.

\section{Numerical symptoms of output degeneracy}\label{app:fault-degeneracy}

The invalid Llama-90B run produced uniform token probabilities consistent
with the zero-hidden-state result in \cref{prop:uniform}.
Direct copies between GPUs on the affected nodes returned zeros without
an execution error, and sharding Llama-11B reproduced the failure.
In the rating task, captured digit mass was $5.45783\times10^{-5}$,
corresponding to seven tokens under the uniform vocabulary distribution.

Across 330 binary prompts in the invalid Llama-90B run, captured mass took
eight distinct values, conditional yes-probability was exactly $0.5$ on
247 rows and undefined on 59 rows. The corrected run produced 330 distinct
captured-mass values and no undefined conditional probabilities.
The rating task produced four distinct expected ratings, all within
$0.007$ of $4.000$, showing why a plausible midpoint did not validate
the measurements. In the controlled diagnostic, zero logit standard
deviation contrasted with approximately $2.139$ in the single-GPU reference
(\cref{tab:app-fault}).
