# Facts ledger — where every number comes from

All numbers are recomputed from the stored result files of the code repository
(`hunghuynh1110/VLM_Audit`, `outputs_bunya/`), not copied from documents.

* `ledger.json` — output of `scripts/report/build_facts_ledger.py`
* `preliminary_diagnostics.json` — output of `scripts/report/preliminary_diagnostics.py`

Both scripts are on branch `claude/bold-archimedes-ro2f9u` of the code repo.
Numbers labelled *prelim* in the LaTeX come from the second file and must be
regenerated by the final analysis script before submission.
