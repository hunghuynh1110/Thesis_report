# Figures

Final figures live here as vector PDF, named after their LaTeX label without
the `fig:` prefix (`capm-dist.pdf` for `\label{fig:capm-dist}`). The full list,
with the data source for each, is in
[`../planning/OUTLINE.md`](../planning/OUTLINE.md) §2.

Every figure is either a plot of measured data generated by a committed script
or a diagram drawn in TikZ. No AI-generated images; no reproduced third-party
photographs.

## Regenerating

    python scripts/make_figures.py                 # all twelve data figures
    python scripts/make_figures.py --only s2-rr    # just one

`scripts/make_figures.py` reads the parquet files of the code repository
(`../VLM_Audit/outputs_bunya/`, branch `claude/bold-archimedes-ro2f9u`) and
`planning/ledger.json`. Point it elsewhere with `--audit-repo PATH`. It needs
pandas, numpy, matplotlib, pyarrow and Pillow.

Nothing in the script estimates or copies a published number; every value is
recomputed from the stored runs. Two figures recompute quantities the ledger
still marks *prelim*, and both reproduce it exactly:

* `s1-perm` enumerates all $\binom{22}{6} = 74{,}613$ keying assignments
  rather than sampling them, giving exact $p$ values of 0.341, 0.196 and
  0.010.
* `s2-rr` runs the cluster bootstrap over queries, $B = 10{,}000$, and
  returns the ledger's intervals for $\Delta\mathrm{RR}$.
