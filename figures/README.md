# Figures

Final figures go here as vector PDF (`.pdf`) where possible, named after their
LaTeX label without the `fig:` prefix (e.g. `capm-dist.pdf` for
`\label{fig:capm-dist}`). The full list, with the data source for each, is in
[`../planning/OUTLINE.md`](../planning/OUTLINE.md) §2.

Every figure must be either a plot of measured data (generated by a committed
script in the code repo) or a diagram. No AI-generated images; no reproduced
third-party photographs.
